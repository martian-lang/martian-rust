Expand description

Represents a newtype that wraps a primitive value.

This allows operations on the inner value of the newtypes.

This is also used as a bound on the endian-encoded types to automatically convert them to and from newtypes if needed.

Dyn Compatibility§

This trait is not dyn compatible.

In older versions of Rust, dyn compatibility was called "object safety", so this trait is not object safe.
